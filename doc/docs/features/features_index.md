# Features Register

Functional capability specifications for Omniwrench.

- **`FR-00001` Cyberpunk Terminal HUD**: ANSI color scheme with neon cyan/magenta styling, glowing borders, live pill badges, and chat bubbles.
- **`FR-00002` Dual Headless / Interactive Mode**: Seamlessly switch between CLI runner mode, daemon server mode, and dual interactive mode.
- **`FR-00003` Sandboxed File Operations**: Safe read, write, exists, and list actions bounded to the workspace directory.
- **`FR-00004` Bounded Subprocess Execution**: Shell execution tool with process timeout safeguards and output capture.
- **`FR-00005` Pluggable Tool Registration**: Dynamic registration of custom Java tools via Spring Component scanning.
- **`FR-00006` WebSocket Telemetry Streaming**: Event broadcasting for agent reasoning steps and subagent status.
- **`FR-00007` Automated Documentation Kit**: Compilation to HTML5, PDF, and Unix Man pages with PlantUML diagram rendering.
