# Goal
Revamp the Omniwrench Terminal UI (TUI) by analyzing the most famous AI terminal agents (OpenCode, Antigravity CLI, OpenClaw, Claude Code, Aider, Crush) and implementing both a Minimal Inline Stream TUI mode and a Full-Screen Dynamically Resizable TUI Workbench mode with dedicated CLI launch options.

# Details
## Context
Terminal AI coding agents require both a lightweight stream-oriented mode that preserves native terminal scrollback and a full-screen multi-pane workbench mode with Home/Session routes, responsive sidebar docking, collapsible reasoning/tool cards, live viewport resizing, and centered command palette modals.
