# Goal
Restructure the Omniwrench project from a single Maven module to a 6-module multi-module build, migrating all existing source code to the correct module boundaries per ADR-0016.

# Details
## Context
ADR-0016 defines the target multi-module structure enabling `omniwrench-core` and `omniwrench-tools` to be usable as standalone libraries. This requires migrating existing code and establishing the Maven module hierarchy.

## Requirements
- [x] [TSK-20260822-006.1] Create root parent `pom.xml` as BOM with shared plugin/dependency management.
- [x] [TSK-20260822-006.2] Create `omniwrench-core` module with engine, models, and SPIs (no Spring).
- [x] [TSK-20260822-006.3] Create `omniwrench-tools` module with all built-in tool implementations.
- [x] [TSK-20260822-006.4] Create `omniwrench-ai` module with AI adapter SPI skeleton.
- [x] [TSK-20260822-006.5] Create `omniwrench-tui` module with Lanterna TUI components.
- [x] [TSK-20260822-006.6] Create `omniwrench-web` module with Spring Web/WebSocket/Security.
- [x] [TSK-20260822-006.7] Create `omniwrench-app` module as Spring Boot assembly.
- [x] [TSK-20260822-006.8] Verify `mvn clean test` passes after migration.
