# Goal
GraalVM SDK Integration, Multi-Architecture Tooling & Dual Distribution Packaging

# Details
## Context
Omniwrench requires full compatibility with the latest GraalVM CE/Oracle releases, automated multi-architecture SDK detection and retrieval tooling, upgraded mock boundary frameworks supporting modern JDKs, and explicit Maven profiles for traditional JVM Fat JAR and GraalVM AOT native binary compilation.
