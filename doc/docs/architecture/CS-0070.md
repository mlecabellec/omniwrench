# Constraint 0070

## Title
Agent operational standards and submission protocols

## Description
- [CS-0070.1] **Mandatory Clearance**: The agent is STRICTLY FORBIDDEN from performing `git commit` or `git push` operations without explicit, unambiguous clearance from the user in the current session.
- [CS-0070.2] **No Assumed Approval**: Even in autonomous modes, clearance for version control mutations MUST be requested and granted for every distinct task.
- [CS-0070.3] **Local Build**: The agent MUST perform a successful local build (`mvn clean test`) of all affected components.
- [CS-0070.4] **Full Test Pass**: The agent MUST execute and verify that ALL relevant unit and integration tests pass successfully.
- [CS-0070.5] **Deletion Analysis**: The agent MUST perform a deletion analysis to confirm that no unintended feature or interface loss has occurred. Any deletion must be justified.
- [CS-0070.6] **Impact Summary**: The agent MUST provide a concise summary of changes explaining the "Why" and "How", along with an impact analysis on dependent modules.
- [CS-0070.7] **Review Recommendation**: The agent MUST recommend a manual review of code changes, highlighting any areas of complexity.
