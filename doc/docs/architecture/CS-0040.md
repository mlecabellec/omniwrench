# Constraint 0040

## Title
Prohibition of literal magic numbers & symbolic limitations

## Description
- [CS-0040.1] **Prohibition of Literal Magic Numbers**: The direct use of literal values (integers, floating-point numbers, or string literals used as identifiers or configuration) within implementation logic is strictly forbidden. All such values must be represented by named symbolic constants.
- [CS-0040.2] **Mandatory Symbolic Limitations**: Any value defining a system limitation must be declared as a symbolic constant (`MAX_REASONING_STEPS`, `DEFAULT_TIMEOUT_SECONDS`, `MAX_THREADS`).
- [CS-0040.3] **Exposure in Interfaces/Headers**: Constants governing public boundaries must be exposed in public interface contracts.
- [CS-0040.4] **Authorized Trivial Literals**: The literals `0`, `1`, and `-1` are authorized without a waiver in trivial loop increment or indexing contexts.
- [CS-0040.5] **Explicit Waivers**: Any other use of a magic number requires a preceding comment containing a strong justification.
- [CS-0040.6] **Naming Convention**: Symbolic constants must use `UPPER_SNAKE_CASE`.
