## Description

Omniwrench shall embed native `llama.cpp` and `ggml` runtimes supporting direct in-process foreign memory and function linking across major CPU architectures (x86_64 AVX2/AVX-512, AArch64 Neon) and GPU backends (CUDA, ROCm, Vulkan, Metal) for both standard JVM and GraalVM AOT Native Image profiles.

## Verification Criteria

1. Host OS and architecture are dynamically identified at runtime (`linux-x86_64`, `linux-aarch64`, `macos-arm64`, `macos-x86_64`, `windows-x86_64`).
2. CPU SIMD capabilities and GPU acceleration layers are configured transparently through typed configuration records (`LlamaCppConfig`).
3. Unit and integration tests verify native loader resolution, parameter propagation, and error containment without external process dependencies.
